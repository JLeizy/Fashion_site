## Стили, тексты и переходы в Figma

SVG не умеет передавать стили и связи вкладки Prototype. Кроме того, импорт SVG в Figma проверен вживую и оказался с особенностями:
- многострочный текст режется на отдельные слои-строки;
- межбуквенный интервал теряется;
- насыщенность шрифта понимается только как Regular и Bold.

Что с этим сделано:
1. **Имена шрифтов в SVG** записаны как `Inter-Medium, Inter`. Figma по первому имени ставит точное начертание, браузер (превью) берёт второе. Это делает `postfix.py`.
2. **Плагин `6_Для_Figma/Плагин_Amfibia`** доводит импорт до готового прототипа:
   - **стили:** 153 цвета, 103 текстовых стиля, 6 теней, сетка;
   - **тексты:** склеивает абзацы обратно (723), возвращает интервалы и начертания, привязывает 22 тыс. текстов к стилям текста и цвета;
   - **переходы:** 5 271 связь — клики, наведение на карточку, заставка через 2,2 с, «назад» в окнах — и 11 стартовых точек (Flows).
3. **Проверка.**
   - В настоящей Figma (тестовый файл «Amfibia — проверка плагина (можно удалить)» в черновиках) проверены: импорт SVG, переходы на группах, текстах и векторах, триггеры «клик», «наведение» и «через N с», действие «назад», цвета, тени, сетка, Flows и шаг «Тексты». На странице «Доставка и оплата» он исправил 127 из 127 текстов и склеил 18 абзацев без ошибок.
   - Окончательные правки шага «Тексты» (интерлиньяж в стилях) проверены на имитации API, собранной из этих SVG (`_инструменты/mock-test.cjs`): всё создаётся, ошибок нет. Последний прогон в Figma упёрся в лимит вызовов Figma MCP на тарифе Starter.

## Как пересобрать (контейнер одноразовый)

```bash
npm ci --ignore-scripts && npm rebuild
```

```bash
cp .env.example .env
```

```bash
mkdir -p .pgdata && chown postgres:postgres .pgdata && chmod 700 .pgdata
```

```bash
npm run setup
```

```bash
npm start
```

Затем из папки `docs/lab25/_инструменты` по порядку:

```bash
node pages.cjs
```

```bash
node extra.cjs
```

```bash
node brands.cjs
```

```bash
node tokens.cjs
```

```bash
node sheets.cjs
```

```bash
node map.cjs
```

```bash
python3 postfix.py
```

```bash
node allprev.cjs
```

```bash
python3 links.py
```

```bash
node instr.cjs
```

```bash
python3 validate.py ..
```

```bash
node mock-test.cjs
```

`node pages.cjs <regex>` (как и `extra.cjs`, `brands.cjs`) пересобирает только экраны, чьё имя подходит под выражение. Пример: `node pages.cjs "Корзина"`. В скриптах стоят абсолютные пути `/home/user/Fashion_site`.
