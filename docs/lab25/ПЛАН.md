## Как сделано

1. Сайт поднят локально с демо-базой. Каждая страница открыта в Chromium на 1920 × 1080 под нужной ролью: гость, покупатель, продавец, кладовщик, курьер, поддержка, владелец. Анимации выключены (`reducedMotion: reduce`).
2. Конвертер DOM → SVG (`_инструменты/capture.js` + `build.cjs`) переводит страницу в векторный SVG:
   - фоны и рамки → прямоугольники;
   - текст → `text` / `tspan` по строкам; он остаётся редактируемым, базовая линия точная;
   - иконки спрайта → векторные группы;
   - фото → прямоугольник с заливкой-картинкой, как при экспорте из Figma, обрезка точно по кадру;
   - canvas, графики и размытые фоны → растровая вставка;
   - псевдоэлементы `::before` / `::after` превращаются в настоящие слои.
3. Имена слоёв — словарь «класс сайта → русское имя» (`names.js`). Повторяющиеся блоки нумеруются. Порядок слоёв читается в Figma сверху вниз, как на странице; при этом там, где блоки перекрываются, сохраняется порядок отрисовки CSS.
4. Состояния открыты настоящими нажатиями: меню, поиск, корзина, окна, шаги оформления, неверный пароль.
5. Каждый SVG проверен строгим XML-парсером (`validate.py`): ошибок нет, ссылки на картинки и градиенты целы.

## Стили и переходы в Figma

SVG не умеет передавать стили и связи Prototype, поэтому они идут отдельно:
- `6_Для_Figma/Плагин_Amfibia` — плагин для приложения Figma: Color, Text, Effect и Grid styles + все переходы (шапка и подвал на каждом экране, меню кабинетов, карточки, сценарии, «Закрыть» = назад) + стартовые точки сценариев. Перед выдачей прогнан на имитации API Figma, собранной из этих SVG (`_инструменты/mock-test.cjs`): ошибок нет.
- `Переходы.csv` — та же таблица для ручной расстановки.
- Архив для Windows собирается `mkzip.py`: имена файлов в UTF-8 с флагом, Проводник показывает их по-русски.

npm run setup
