## Правила для слоёв

- Корневая группа = имя фрейма (`Главная_1920`), подложка — `Фон_Главная_1920`.
- Секции по-русски: `Шапка`, `Первый_экран`, `Новые_коллекции`, `Бренды`, `Рассылка`, `Подвал`, `Фильтры`, `Сетка_товаров`, `Карточка_товара_1`…
- Подложки блоков — `Фон_…`, линии — `Линия`, иконки — `Иконка_поиск`, `Иконка_корзина`…
- Текстовый слой называется своим текстом. Лишних обёрток вокруг текста нет (в maket-anime были `Права` → `Права_2`, так больше не делаем).
- В SVG секции идут в обратном порядке. Тогда в панели слоёв Figma они читаются сверху вниз, как на странице. Абсолютно позиционированные элементы (бейджи поверх фото) остаются выше своих соседей.
- Фото товаров и показов — настоящие, из `public/images/brands/…`. Они вшиты в SVG как JPEG, качество ≈78, размер — по месту на макете.
- Шрифты сайта: UnifrakturMaguntia (логотип), Cormorant Garamond (заголовки), Inter (текст), JetBrains Mono (метки). Все есть в Figma.

## Способ (этап 2)

1. Поднять сайт локально (команды ниже) и открыть каждую страницу в Playwright на 1920×1080 с `reducedMotion: 'reduce'`. Без анимаций нет SplitType и WebGL, контент показывается сразу.
2. Конвертер DOM → SVG (`page.evaluate`):
   - фон и рамка → `rect`;
   - `img` → `image` (cover → `slice`);
   - инлайн-иконки `<use href="#i-…">` → вставить символ из спрайта;
   - текст → `text` / `tspan` по строкам (Range.getClientRects, базовая линия через `fontBoundingBoxAscent`);
   - `canvas` → растровый снимок области.
3. Имена слоёв — словарь «CSS-класс → русское имя» плюс точечные `data-layer` для конкретных страниц.
4. Длинные страницы обрезать до разумной высоты. Сейчас главная — 19 461 px, история бренда — 96 544 px; оставить 1–2 экрана каждой повторяющейся секции и подвал.
5. Состояния (мега-меню, поиск, мини-корзина, шаги оформления) — отдельные фреймы.

## Как поднять сайт заново (контейнер одноразовый)

```bash
npm ci --ignore-scripts && npm rebuild
```

```bash
cp .env.example .env
```

Если запуск идёт от root, PostgreSQL не может сам создать папку данных — создать её заранее:

```bash
mkdir -p .pgdata && chown postgres:postgres .pgdata && chmod 700 .pgdata
```

```bash
npm run setup
```

```bash
npm start
```

Пробные снимки страниц: `node docs/lab25/_инструменты/shoot.cjs / /catalog /brand/balenciaga '/product/{P}'` (вход под buyer@amfibia.by).
