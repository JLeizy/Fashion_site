КАК ИМПОРТИРОВАТЬ В FIGMA
-------------------------
1. Создай в файле Figma страницы: «Стили», «Компоненты», «Прототип»,
   «Обложка», «Карта переходов».
2. Перетащи SVG в окно Figma (или File → Place image, Ctrl+Shift+K).
   Каждый SVG становится фреймом с именем файла, например
   «01_Главная_1920». Папку 3_Прототип/01_Витрина удобно положить
   в секцию «Витрина», 02_Покупка — в «Покупка» и т. д.
3. Тексты — редактируемые. Шрифты сайта — бесплатные Google Fonts, они
   есть в Figma: UnifrakturMaguntia (логотип), Cormorant Garamond
   (заголовки), Inter (текст), JetBrains Mono (метки, кнопки, цены).
   Все шрифты в файлах: JetBrains Mono, Inter, Cormorant Garamond, UnifrakturMaguntia, Forum, Playfair Display, Unbounded, Rubik Glitch, Caveat.
   Если Figma пишет «Missing fonts» — нажми Replace fonts и выбери
   ближайший похожий (или установи шрифт с fonts.google.com).
4. Фото товаров и показов вшиты в SVG: в Figma они — прямоугольники
   с заливкой-картинкой (как при экспорте из самой Figma), их можно
   заменить через панель Fill.
5. Большой файл (главная — около 2 МБ) импортируется 5–15 секунд.

СТРУКТУРА СЛОЁВ
---------------
Слои названы по-русски и читаются сверху вниз так же, как страница:
    Шапка → Навигация, Логотип, Иконки (Кнопка_Поиск, Кнопка_Корзина…)
    Первый_экран → Слайд, Затемнение, Текст_слайда, Кнопки, Управление_слайдером
    Каталог → Фильтры (Фильтр_1… → Чекбокс_Balenciaga…), Выдача →
              Панель_сортировки, Сетка_товаров → Карточка_товара_1…24 →
              Фото_товара, Метки, Описание (Бренд, Название, Цена, Звёзды)
    Подвал → Рассылка, Колонки_ссылок, Нижняя_строка
Повторяющиеся блоки пронумерованы: Карточка_товара_1, _2…
Подложки — «Фон_<блок>», рамки — «Рамка», линии — «Линия_снизу» и т. п.
Текстовый слой называется смыслом («Цена», «Название») или своим текстом.

ЧТО ДОДЕЛАТЬ В FIGMA (SVG этого не переносит)
---------------------------------------------
1. Стили: создать Color styles и Text styles по странице «Стили».
2. Auto layout: блоки импортируются группами. Выдели группу (например,
   «Карточка_товара_1»), Shift+A — получится фрейм с автолейаутом.
3. Компоненты: на странице «Компоненты» выдели группу → Ctrl+Alt+K.
4. Сетка фрейма: Layout grid → Columns 12, Margin 100, Gutter 24.
5. Переходы (вкладка Prototype): выдели кнопку или ссылку на экране,
   потяни синий кружок к нужному фрейму. Список переходов — ниже,
   тот же, что на «Карте переходов». Для модальных окон и мини-корзины
   ставь Open overlay, для остального — Navigate to, анимация Dissolve.

КАК СДЕЛАНО
-----------
Прототип снят с работающего сайта Amfibia (Express + PostgreSQL, демо-база):
каждая страница открыта в браузере на 1920 px под нужной ролью
(гость, покупатель, продавец, кладовщик, курьер, поддержка, владелец),
с реальными товарами, ценами, заказами и фото, и переведена в векторный
SVG с именованными слоями. Состояния (меню, поиск, мини-корзина, окна,
шаги оформления, ошибки форм) открыты настоящими нажатиями.
Размер папки ≈ 63 МБ.
