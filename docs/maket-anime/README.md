# Дизайн-макет «Мультивселенная аниме» — SVG для Figma

Всё сделано по ТЗ: 4 страницы, каждая в трёх версиях (1440 / 768 / 375). Это 12 фреймов, плюс отдельные страницы «Стили», «Компоненты» и «Обложка».

## Что внутри

| Файл / папка | Куда положить в Figma |
|---|---|
| `00_Обложка.svg` | страница **Обложка** (1920×1080) |
| `01_Стили.svg` | страница **Стили**: палитра из 12 цветов, 18 текстовых стилей, 3 сетки |
| `02_Компоненты.svg` | страница **Компоненты**: 10 компонентов со всеми вариантами |

| `Макет_768/` | та же страница, секция «Планшет 768» |
| `Макет_375/` | та же страница, секция «Мобильный 375» |
| `Картинки/` | 22 картинки в JPG с латинскими именами, по слотам из раздела 10 ТЗ |
| `Превью/` | как выглядит каждый файл |

## Как импортировать

1. Создайте в Figma страницы `Стили`, `Компоненты`, `Макет`, `---`, `Обложка`.
2. Перетащите SVG-файл на нужную страницу. Каждый файл станет фреймом с именем файла, например `Главная_1440`.
3. Внутри фрейма слои уже названы по-русски, как требует ТЗ:
   - секции: `Шапка`, `Первый_экран`, `Миры`, `О_проекте`, `Сюжет`, `Персонажи`, `Система_силы`, `Оценка`, `Следующий_мир`, `Подвал`;
   - элементы: `Логотип`, `Навигация`, `Текстовый_блок`, `Карточка_Ичиго`, `Картинка_Б-3_Ичиго` и т. д.

   Слоёв `Frame 12` или `Rectangle 5` нет. Подложки называются `Фон_…`.
4. Тексты импортируются редактируемыми (шрифты Unbounded и Inter есть в Figma). Картинки уже стоят в своих слотах как заливка.

## Что SVG не переносит — это доделывается в Figma по ТЗ

- **Стили.** Цветовые, текстовые и стили сеток нужно создать (разделы 4, 5, 11 ТЗ). Все значения есть на странице `Стили`. После этого назначьте стили слоям: «Selection colors» → стиль.
- **Auto layout и компоненты** (разделы 6, 12, 13). После импорта блоки будут группами. Чтобы сделать из группы Auto layout-фрейм:
  1. удалите внутри подложку `Фон_…`;
  2. выделите группу и нажмите Shift+A;
  3. задайте фрейму заливку, обводку и скругление стилями.

  Размеры, отступы и промежутки взяты из ТЗ, поэтому значения для Auto layout сверяйте с ТЗ.
- **Сетки** на фреймах: Columns 12/8/4 (раздел 3). Все карточки и блоки уже стоят по колонкам.

## Отступления от ТЗ (по делу)

- **Факты на первом экране мира** — сетка 2×2, а не 4 в ряд по 160 px. В шрифте Unbounded значения «приключения», «Toei Animation», «Драма, комедия» не влезают в 160 px и вылезали бы за карточку.
  - На десктопе ширина карточки 282 px (3 колонки), на планшете — 254 px.
  - На мобильном карточки 163,5 px по ТЗ, а два длинных слова перенесены с дефисом: «приклю-чения», «Ani-mation».
- **Фон первого экрана главной (Г-1)** — коллаж из трёх артов, как разрешает ТЗ.
