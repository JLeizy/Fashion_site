# Amfibia — журнал прогресса

> В начале каждой новой сессии: прочитать ТЗ (`Итоговый.txt` / `Amfibia_TZ.md`) и этот файл, затем продолжить с первого невыполненного этапа.
> Легенда: ✅ готово и проверено · 🟡 в работе · ⬜ не начато

## Окружение
| Что | Значение |
|---|---|
| Node.js | v24.21.0 (установлен пользователем) |
| PostgreSQL | Свой PostgreSQL 15+ (`USE_EMBEDDED_PG=false`, данные `PG*` в `.env`) **или**, если в системе его нет, встроенный PostgreSQL 18.4 из npm-пакета `embedded-postgres` (devDependency): бинарники в `node_modules`, данные в `.pgdata/`, порт 5433. Ничего не ставится в систему. Переключение на свой PostgreSQL — `USE_EMBEDDED_PG=false` и свои `PG*` в `.env`. |
| Расширения БД | `pg_trgm` (триграммный поиск) — доступно и в embedded, и в стандартной поставке PostgreSQL для Windows |
| Запуск | `npm run setup` (схема + наполнение + заглушки), затем `npm start` → http://localhost:3000 |

## Решения и отступления от ТЗ (правило 0.4)
1. **PostgreSQL не установлен** → встроенный PostgreSQL из npm-пакета (см. «Окружение»). Код работает с любым PostgreSQL 15+.
2. **Шрифты Google Fonts** подключены локально через npm-пакеты `@fontsource/*` (это те же шрифты Google Fonts, но сайт работает и без интернета). У UnifrakturMaguntia нет кириллицы, поэтому готика — только для латиницы (логотип, названия брендов), русские заголовки — Cormorant Garamond.
3. **WebGL** — библиотека OGL (≈30 КБ вместо ≈600 КБ у Three.js): для шейдеров искажения и «жидкого» перехода слайдов её достаточно.
4. **Переходы страниц**: межстраничные View Transitions поддерживаются в Chrome/Edge (и Safari); в Firefox работает JS-шторка.
5. **Выбор цвета на странице товара**: в ТЗ у товара один цвет, варианты — только размеры. Добавлен столбец `products.model_code`: товары одной модели в разных цветах связаны и переключаются кружками-образцами.
6. **SVG-заглушки** открываются через `<img>`, а в таком режиме браузер не грузит веб-шрифты внутрь SVG, поэтому текст в заглушках набран системными шрифтами.
7. **Оплата картой — имитация**: номер карты проверяется алгоритмом Луна на клиенте и **не отправляется на сервер** (сохраняются только последние 4 цифры в комментарии к оплате).
9. **Курьер назначается автоматически** (реализовано: `orderService.assignCourierIfMissing`, вызывается складом при «Передать в доставку») при передаче в доставку (`handed_to_delivery`), если его не назначил владелец: выбирается курьер с наименьшим числом активных заказов; владелец может переназначить в админке (этап 14). Иначе цепочка склад → курьер не работала бы без админки.
10. **Возврат на склад**: заказ переходит в `returned` (оплата → `refunded`) только когда склад принял ВСЕ позиции по одобренным возвратам (`orderService.markReturned`); при частичном возврате заказ остаётся «Доставлен», а возврат денег по позиции отражается уведомлением покупателю.
12. **Админка: возвраты, обращения и остатки** открываются ссылками в рабочие кабинеты поддержки и склада (`/account/desk`, `/account/stock`) — owner имеет туда доступ; дублировать эти интерфейсы в `/admin` не стали. Тема админки хранится отдельно (`amf:admin-theme`, по умолчанию тёмная).
13. **Справочники в админке** — один обобщённый CRUD по белому списку таблиц и столбцов (`adminRefs.js → ENTITIES`): имена таблиц/столбцов в SQL берутся только из словаря, значения — параметрами.
11. **Удаление товара продавцом**: если товар уже заказывали или он лежит на складе, он не удаляется, а снимается с публикации (draft) — иначе пропала бы история заказов и движений.
8. Объём историй (15 × ~15 000 слов ≈ 225 000 слов) — пишутся отдельными этапами, по одному бренду; английская версия сокращённая (3–5 тыс. слов), как разрешено в ТЗ.

## Известные проблемы и заметки
- Если в облачной/новой среде PostgreSQL остановлен: `service postgresql start` (или свой PostgreSQL / `USE_EMBEDDED_PG=true`).
- Репозиторий проекта: `Fashion_site` (импорт из JLeizy/Test, история этапов ведётся коммитами по блокам).
- Исправлено на этапе 13: на телефоне меню кабинета растягивало страницу по ширине (сетка `.acc` → `minmax(0, 1fr)`).
- Скриншоты Playwright: прелоадер отключается `sessionStorage.setItem('amf:preloaded','1')` через `addInitScript`.
- По просьбе заказчика убрана верхняя бегущая строка над шапкой (строгий стиль магазина).
- Ссылки на `/history/:slug`, `/histories` (этап 15) пока ведут на 404.
- При тестах curl из Git Bash на Windows кириллица в теле запроса портится — отправлять JSON из UTF-8 файла (`--data-binary @file`).
- Во встроенной панели браузера, когда она скрыта, `requestAnimationFrame` и View Transitions «замирают» — открытие панелей переведено на reflow-приём (`showAnimated`).
